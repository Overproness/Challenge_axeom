## Working system, cost and limits

The mobile Owner Desk opens with three decisions: save Price, review cash, close missing instructions. Client pages connect every source. Multi-file uploads validate atomically, upsert stable IDs, deduplicate messages, and recalculate everything. Unknown references, repeated titles and novel requests remain reviewable. Approval creates a local task or updates board notes; **nothing is sent automatically**.

It is buildless HTML/CSS/JavaScript on Sites, with browser storage and no application server or paid runtime API calls. Code, deterministic processing and API usage cost **$0/month**. Sites hosting uses the available account entitlement; its allowance is not exposed here, so unlimited free hosting is not claimed. There is no cross-device database, inbox sync, direct sending or automatic billing. New identity/semantic arrangements may require review. Tests cover financial invariants, audited mappings and unseen uploads; 58 phone/desktop browser checks passed on the published Jev version. This is browser emulation, not a physical-phone usability study.
